# iOS App Development Projects

A collection of iOS application exercises built with Swift and Xcode. The repository includes several independent app projects developed while learning native Apple-platform development.

## Projects

- **Calculator** — an iOS calculator application project.
- **CurrencyConverter** — a currency conversion application project.
- **Clock App** — a clock-focused app exercise.
- **Adventure App** — an interactive app exercise.

## Technology

- Swift
- Xcode
- UIKit and Interface Builder
- Storyboards and asset catalogs

## Run locally

1. Install Xcode on macOS.
2. Clone this repository.
3. Open the relevant `.xcodeproj` file in Xcode.
4. Select an iOS simulator or connected device.
5. Build and run the selected target.

Each project is maintained separately. Open the project file inside its corresponding folder.

## Status

Educational portfolio collection. Individual projects may need compatibility updates for current Xcode and iOS versions. Screenshots, feature details, and test status should be added after verifying each app in the simulator.

## Repository hygiene

Personal Xcode workspace state and user-specific settings are excluded from version control via `.gitignore`.
